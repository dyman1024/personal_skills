# 视觉规范

[assets/template.html](../assets/template.html) 已实现本规范。改动样式时先改模板里的变量，不要在组件里写字面颜色。

## 配色

白底，黑字，灰字；浅蓝是唯一的强调色；浅红、浅黄、浅绿只表示状态。页面只有一套浅色主题，所以在 `:root` 写 `color-scheme: light`，并给 `body` 设置明确的背景色。

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#ffffff` | 页面和方框底色 |
| `--ink` | `#15171a` | 正文、标题、图中主文字 |
| `--muted` | `#6b7077` | 辅助文字、图注、图中说明 |
| `--faint` | `#9ba0a6` | 普通连线、箭头 |
| `--line` / `--line-strong` | `#e4e6e9` / `#c7cbd0` | 表格线、方框描边 |
| `--panel` | `#f6f7f8` | 分区底色、表头、代码底色 |
| `--blue-50` / `--blue-100` | `#eef5fd` / `#dcebfb` | 关口方框、通道底色 |
| `--blue-300` / `--blue-500` | `#93c1ee` / `#4a90d9` | 强调线、主路径连线 |
| `--blue-text` | `#2f73bf` | 链接、编号、图中强调文字 |
| `--red-50` / `--red-300` / `--red-text` | `#fdeeee` / `#f0aaaa` / `#c0453f` | 拒绝、错误码、保护面 |
| `--yellow-50` / `--yellow-300` / `--yellow-text` | `#fdf6df` / `#ecd385` / `#9a7200` | 等待、需确认、暂停、启动中 |
| `--green-50` / `--green-300` / `--green-text` | `#e9f6ed` / `#a3d6b1` / `#2e8549` | 放行、运行、就绪、成功 |

颜色语义：

- **浅蓝**：关口（gateway、检查、协议边界）、主调用路径、编号。一张图里浅蓝元素不超过三分之一。
- **浅红**：拒绝结果、错误码、禁止区域。
- **浅黄**：需要用户确认、挂起等待、过渡状态。
- **浅绿**：允许、运行中、终态成功。
- 其他一律白底灰框黑字。不要用颜色区分模块类别，用分区和标题区分。

如果用户要求深色主题，按 Artifact 的规则把每个变量在 `prefers-color-scheme: dark` 和 `[data-theme="dark"]` 下各定义一次，不要只改个别组件。

## 字体与字号

- 正文：`IBM Plex Sans` + `Noto Sans SC`，15.5 px，行高 1.72，段落最宽约 74 个中文字符。
- 标题：`Noto Sans SC` 700。h1 26–36 px，h2 25 px，h3 17 px。
- 代码和标识符：`IBM Plex Mono`。
- 图中：标题 13.5 px 600，正文 12.5 px，说明 11.5 px，等宽 11.5 px。

## 版式

- 内容区最宽 1120 px，左右边距 24 px（手机 16 px），区块间距 64 px。
- 图放在带细边框的容器里，容器可横向滚动；SVG 的 `min-width` 为 760 px，总图为 1000 px。
- 手机宽度下网格变成单列，页面本身不能横向滚动。

## 组件

| 组件 | 用法 |
| --- | --- |
| 眼眉 `.eyebrow` | 页头第一行，写“内部技术分享 · 项目名” |
| 事实行 `.facts` | 卡片、PR 数、增删行数、代码基线；数字加粗 |
| 讲法 `.talk` | 建议的讲解顺序和各节分钟数 |
| 标签行 `.tag` | 每节第一行：“分 · ③ · PR 链接 · 关键代码路径” |
| 编号标题 `h2 .no` | 子模块编号用浅蓝 |
| 模块卡片 `a.panel.mod` | 总图下方，三列，每张卡片链接到对应节 |
| 规则条 `.rules` | 3–5 条贯穿全篇的设计规则，每条一个粗体短语加一句话 |
| 面板 `.panel` | 两栏补充说明：边界、实现细节、新增错误码 |
| 状态胶囊 `.chip.c-red` 等 | 表格里的状态标记 |
| 表格 `.tbl` | 矩阵、合约改动、恢复策略；不用表格画流程 |

## 写在页面里的数字

- 行数、PR 数、时长、阈值都要带单位，并能追溯到工具输出或代码常量。
- 模拟器或单机测得的数字在图注里注明“模拟器”“实测”。
