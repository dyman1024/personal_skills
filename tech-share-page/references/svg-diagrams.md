# SVG 原理图规则

所有图都是手写的内联 `<svg>`，不用图库和外部图片。样式类在模板里定义，图里只写类名。

## 1. 画布和网格

- `viewBox="0 0 1100 H"`，宽度固定 1100，高度按内容定。CSS 让它缩放到容器宽度。
- 坐标对齐 2 的倍数；同一行的方框用相同的 `y` 和高度，同一列用相同的 `x` 和宽度。
- 方框高度：单行 40，两行 52–56，三行 64–80。文字离框边 12–16 px。
- 分区（`zone`）比里面的方框大 16–24 px，标题放在分区左上角。

## 2. 绘制顺序（最重要）

SVG 按书写顺序绘制，后画的形状盖住先画的。按这个顺序写：

1. 分区背景 `zone`、通道 `chan`。
2. 方框 `box`、`gate`、`rbox`、`ybox`、`gbox`、`iso`。
3. 方框里的文字。
4. **连线和箭头**，最后写，至少晚于它穿过的所有分区和方框。
5. 连线上的标签。

典型错误：跨两个分区的长连线写在后一个分区之前，结果连线在后一个分区内被盖住，箭头看不见。`svg_lint.py` 把这种情况报为 `occluded`。

## 3. 箭头

每张图在 `<defs>` 里定义自己的 marker，id 用图的前缀，例如总图 `o1m`（灰）、`o1a`（蓝）：

```svg
<defs>
  <marker id="o1m" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="7" markerHeight="7" orient="auto-start-reverse"><path d="M0,0 L10,5 L0,10 z" class="hm"/></marker>
  <marker id="o1a" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="7" markerHeight="7" orient="auto-start-reverse"><path d="M0,0 L10,5 L0,10 z" class="ha"/></marker>
</defs>
```

规则：

- 实线表示“流向”，带箭头；汇聚时同一组线只在最后一条带箭头（见下文）。虚线（`dash`）表示“关联”，不带箭头。
- 箭头尖停在目标边框外 2 px。连线可以是斜线，直接从来源的边连到目标的边。
- 双向连线同时用 `marker-start` 和 `marker-end`。
- 连线颜色有含义：`la` 蓝 = 主路径或关口放行，`ln` 灰 = 普通，`lr` 红 = 拒绝，`lg` 绿 = 放行到终态。
- 走折线（`path` 的 `H`、`V`）绕开方框，不要斜穿别的方框。
- 时序图的生命线用 `life` 类，不带箭头。

### 汇聚和分发用直连斜线

多个来源汇入一个目标：每个来源从右边中点画一条直线到目标左边，落点沿目标的边自上而下错开 6–8 px，顺序和来源一致；只在最后一条（最下面一条）画箭头，表示这一组线汇进同一个入口。

```svg
<!-- 三个来源（右边中点 y=44、98、152）汇到目标左边 x=340，落点 y=150、158、166 -->
<line class="ln" x1="260" y1="44" x2="338" y2="150"/>
<line class="ln" x1="260" y1="98" x2="338" y2="158"/>
<line class="ln" x1="260" y1="152" x2="338" y2="166" marker-end="url(#p1m)"/>
```

一个来源分发到多个目标：从来源右边中点附近出发（起点上下错开 2 px，避免重叠成一点），向每个目标各画一条带箭头的直线，落在目标左边的中点。

```svg
<!-- 关口右边 x=590，分发到三个目标（左边 x=660，中点 y=48、110、172） -->
<line class="la" x1="590" y1="166" x2="658" y2="48" marker-end="url(#p1a)"/>
<line class="la" x1="590" y1="168" x2="658" y2="110" marker-end="url(#p1a)"/>
<line class="la" x1="590" y1="170" x2="658" y2="172" marker-end="url(#p1a)"/>
```

判定树的根节点、一个检查分出几种结果，也用这种分发画法。

## 4. 文字

- 字号：方框标题 `ts` 13.5，正文 12.5，说明 `tm` 11.5，等宽 `tc`/`tk` 11.5；强调 `tb`（蓝）、`tr`/`trc`（红）、`ty`/`tyc`（黄）、`tg`（绿）。
- 宽度估算：中文和全角标点 1.0 em；拉丁小写约 0.55 em，大写约 0.68 em；等宽 0.6 em。例如 11.5 px 的“结果外包一层 &lt;tool-output&gt;”约 6×11.5 + 13×6.3 ≈ 151 px。
- 放不下就缩短文字或换行，不要缩小字号。
- 标签离连线至少 6 px，放在水平线上方或竖线右侧；竖线旁的长标签用 `text-anchor="end"` 放在左侧。
- `<`、`>`、`&` 写成 `&lt;`、`&gt;`、`&amp;`。
- 竖排的分组标签用 `transform="rotate(-90 x y)"`，旋转后的文字不参与宽度检查，要自己确认。

## 5. 图谱

按要回答的问题选图。

| 图 | 回答什么 | 骨架 |
| --- | --- | --- |
| 分层模块总图 | 系统由什么组成，谁和谁通信 | 左侧用户列；横向分层带（如 Agent 层、服务端、通道、客户端）；客户端按进程或执行身份分区；关口用 `gate`；圈号标出子模块；跨层连线最后画 |
| 调用路径泳道图 | 一次请求经过哪些关口 | 顶部泳道头；虚线生命线；横向消息箭头带标签；在泳道上用 `gate` 注释框写这一步检查什么 |
| 状态机 | 生命周期和恢复 | 状态框按语义上色（就绪绿、启动中黄、失败红）；入口用实心圆点；迁移线标事件；回到早期状态用三次贝塞尔弧线；右侧放“触发时机”说明框 |
| 判定树 | 一条规则怎么判断 | 左侧根节点向每个分类节点各连一条带箭头的斜线 → 判定节点（`gate`）→ 结果（`rbox` 拒绝 / `gbox` 允许），“是 / 否”标在分支旁 |
| 有序检查管线 | 检查顺序和每步的拒绝码 | 竖向步骤框加下行箭头；右侧两列文字：拒绝码（红色等宽）、为什么排在这里；左侧用括号和竖排文字标出属于哪个函数或阶段 |
| 汇聚—关口—分发 | 一个入口收住多条路径 | 左列入口用汇聚斜线连到关口（最后一条带箭头）→ 关口用分发斜线连到右列适配器（每条带箭头）；关口下方画拒绝分支 |
| 条件 AND 图 | 几个条件同时成立才放行 | 左列条件框（写清每个事实由谁观察）各连一条斜线到胶囊节点左边，最后一条带箭头 → “是”到绿框、“否”到红框 |
| 阶梯 | 多级能力或代价递增 | 横条逐级排列；每级一个身份胶囊和一个状态胶囊；右侧一条下行箭头写“越往下越……” |
| 防线链 | 多层防护如何串联 | 两行流程，第一行输入和模型，折线转到第二行的防线；底部用一个绿色胶囊总结哪些是结构保证 |
| 矩阵 | 两个维度的分类 | 用 HTML 表格，不用 SVG；行头写判定规则，列头写执行身份和适用渠道 |

## 6. 每张图的外壳

```html
<figure>
  <div class="fig">
    <svg class="dg" viewBox="0 0 1100 300" role="img" aria-label="一句话写这张图的结论">
      ...
    </svg>
  </div>
  <figcaption><b>结论短语。</b>图里没写的约束、数字和来源。</figcaption>
</figure>
```

总图用 `<div class="fig wide">`，让它在窄屏上横向滚动，而不是缩得看不清。

## 7. 检查

```bash
python3 scripts/svg_lint.py page.html
```

| 级别 | 类型 | 含义和修法 |
| --- | --- | --- |
| error | `parse` | SVG 不是合法 XML；检查未闭合标签和未转义的 `<`、`&` |
| error | `marker-id` | marker id 在页面里重名；给每张图换前缀 |
| error | `occluded` | 连线被后画的形状盖住；把连线移到这些形状之后 |
| error | `viewbox` | 文字超出画布；缩短文字或调整位置 |
| warn | `overflow` | 文字越过所在方框的边；缩短、换行或加宽方框 |
| warn | `no-head` | 实线停在形状边上，同一条边上也没有带箭头的同组线；补上箭头，或改成虚线关联 |
| warn | `text-line` | 文字压在连线上；把标签移开至少 6 px |
| warn | `text-text` | 两段文字重叠 |
